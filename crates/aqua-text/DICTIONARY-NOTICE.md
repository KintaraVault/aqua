# Dictionary notices

The bundled English and Russian word-frequency data is a bounded selection (up to 30,000 alphabetic entries per language) from [SymSpell.FrequencyDictionary](https://github.com/wolfgarbe/SymSpell/tree/master/SymSpell.FrequencyDictionary), distributed in the SymSpell MIT-licensed repository. See DICTIONARY-LICENSE.

Upstream derives frequencies from Google Books Ngrams intersected with Hunspell word lists, and provides the generation script and provenance in that directory. The bundled data is public dictionary data, not user-generated input. The small seed dictionary was written for Aqua.
